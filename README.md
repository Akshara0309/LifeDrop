# LifeDrop

## Project Overview
LifeDrop is a Smart Blood Donation & Emergency Blood Management System that connects blood donors, patients, hospitals, and blood banks through a secure platform.

## Mission
No life should be lost because blood could not be found in time.

## Vision
To build a trusted digital ecosystem that makes blood donation faster, safer, and more accessible.

## Features
- Donor Registration
- Recipient Registration
- Blood Search
- Emergency Blood Requests
- Blood Bank Search
- Donation History
- Smart Notifications
- Blood Circle
- Donation Buddy
- AI Assistant

## Technology
Technology stack will be finalized during development.
